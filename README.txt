GLOBALVEDA LABS WEBSITE STARTER
================================

Files:
- index.html: website structure
- styles.css: responsive black-and-gold styling
- script.js: mobile navigation and services dropdown
- globalveda-logo.png: logo image supplied by you, adapted for the dark header

HOW TO RUN:
1. Extract this ZIP.
2. Open the folder in Visual Studio Code.
3. Install the "Live Server" extension (optional).
4. Right-click index.html and choose "Open with Live Server".
   Or simply double-click index.html to open it in a browser.

CUSTOMIZE:
- Replace the telephone number 8638424729 in index.html with the confirmed business number if needed.
- Update service links and page content as the website grows.
- The current buttons and navigation are starter links; forms, quote submission, file uploads,
  training registration and franchise applications need backend integration later.
